# Basketball Stats 使い方ガイド

Basketball Stats Writer / Reader の公式ガイド・サポートサイトです。

公開URL: <https://bbstatsapp.github.io/basketball-stats-support/>

## ページ構成

- `index.html` — ガイドの入口と操作動画
- `writer.html` — Writerの使い方
- `reader.html` — Readerの使い方
- `sharing.html` — ファイル共有の説明
- `faq.html` — よくある質問
- `privacy.html` — プライバシーポリシー
- `contact.html` — お問い合わせ

画像と動画は `assets/` に配置しています。外部ライブラリやビルド工程を使わない静的サイトのため、`main` ブランチへ反映するとGitHub Pagesからそのまま配信できます。

## ローカル確認

```sh
python3 -m http.server 4173
```

起動後、<http://127.0.0.1:4173/> を開きます。
